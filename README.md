# تطبيق الحفظ (تاريخ، جغرافيا، مدنية، إسلامية، علوم)

1. **المحتوى**: عدّل `data.js` (مادة ← مقاطع ← دروس ← أسئلة وأجوبة) وضع ملفات PDF في مجلد `pdf/`.
2. **قاعدة البيانات**: أنشئ مشروع Firebase ثم فعّل Firestore، وضع بياناته في `firebase-config.js`.
   قواعد Firestore المقترحة: `match /results/{id} { allow create: if true; allow read, delete: if true; }`
3. **النشر**: ارفع المجلد إلى مستودع GitHub ثم Settings ← Pages ← Branch: main.
النتائج تُحفظ في مجموعة `results` (الاسم، المادة، الدرس، النتيجة، التاريخ).

## إضافة درس
في `data.js` أضف أسئلة الدرس في `qs` بالشكل: `['السؤال','الجواب الصحيح','خطأ1','خطأ2','خطأ3']` (ترتيب الخيارات يُخلط تلقائيًا). ضع ملف PDF باسم معرّف الدرس في `pdf/` (مثال: درس التاريخ الأول من المقطع الأول ← `h11.pdf`).
المعرّفات: التاريخ h، الجغرافيا g، المدنية c، العلوم s (مثال g23 = المقطع 2 الدرس 3)، الإسلامية i (i12 = الفصل 1 الدرس 2).
## لوحة الأستاذ
من الصفحة الرئيسية ← «دخول الأستاذ» ← الرقم السري (ADMIN_PIN). تعرض المعدل لكل تلميذ وآخر النتائج مع حذف.

## كتابة الخيارات
اجعل الخيارات الخاطئة قريبة من الصحيح: بدّل فيها أجزاء من الدرس نفسه (مراحل مقلوبة، تعريف نقطة مكان أخرى...) حتى لا يخمّن التلميذ الجواب بالاستبعاد.

## الامتحانات (Firestore)
قواعد إضافية: `match /exams/{id} { allow read: if true; allow write: if true; }`
الدخول للأستاذ برقم سري: ضعيه في `ADMIN_PIN` داخل `firebase-config.js`.
